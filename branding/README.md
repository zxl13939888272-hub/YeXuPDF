# YeXuPDF branding

`yexupdf-icon-master.png` is the editable 1536 × 1536 source artwork for the YeXuPDF launcher icon.

- Created for this project with OpenAI ImageGen on 2026-11-06.
- Generation mode: new image, square raster artwork, no external reference image.
- Art direction: a premium charcoal-black app tile with a flowing layered-paper emblem, soft champagne-metallic highlights, restrained gold edges, clean geometry, no text, and no mockup background.
- The Android launcher PNGs in `app/src/main/res/mipmap-*` are resized and masked derivatives of this master.
